# Silverbullet Documentation

Mi documentación personal alojada en Silverbullet con su configuración.


## Estructura

- `documentacion/` - Índice de temas (sistema, programación, redes, etc.)
- `configuration/` - Configuración de Silverbullet
- `index.md` - Página principal

## Configuración principal

Archivo `CONFIG.md` con configuración de treeview, plugs y reglas de exclusión.
